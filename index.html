      GPS Accuracy Overlay

      On a ride's summary map, colors the route and dots each recorded point by GPS accuracy instead of speed — green is precise, red is imprecise — and flags the single best and worst points. Gaps between dots show where GPS dropped out.

      Precise Imprecise No accuracy data, or clipped warm-up
      Clip GPS Warm-up

      Grays out the start of the route until GPS accuracy settles down, so a shaky first fix doesn't skew the accuracy overlay's colors. Only affects the overlay above.
